# เริ่มเล่น v15 — สวมใส่ไอเทม + Tamer Information

## เปิดโปรเจกต์

1. แตก ZIP เป็นโฟลเดอร์ใหม่ `mobile_equipment_v15` เพื่อไม่ปะปนไฟล์เก่า
2. Godot Project Manager → Import → เลือก `project.godot` ในโฟลเดอร์นี้
3. ใช้ Godot 4.4.1 Standard หรือใหม่กว่า และรอ Import รูป/SVG ให้ครบ
4. กด F5 เล่นเกม แล้วแตะปุ่ม **อุปกรณ์** ด้านบนขวา ข้างปุ่ม Status

## วิธีใช้หน้าต่าง

- **Tamer**: ช่องศีรษะ แว่น เสื้อ กางเกง ถุงมือ รองเท้า หลัง สร้อย แหวน ข้อมือ เข็มขัด เครื่องราง
- **Digivice**: ช่อง Digivice และ Chip A / Chip B เพิ่มพลังคู่หู
- **Skill**: แสดงสกิลของร่างคู่หูปัจจุบัน ชื่อ/ตัวคูณ/คูลดาวน์อ่านจากข้อมูลจริง
- เลือกไอเทมในกระเป๋า → ดูค่าสเตตัส/ความต่างจากของเดิม → แตะ **สวมใส่**
- แตะช่องที่สวมอยู่ → **ถอดอุปกรณ์** เพื่อคืนเข้ากระเป๋า
- ใส่ของทับช่องเดิมแล้วของเก่าจะคืนเข้ากระเป๋า ไม่หายหรือเกิดสำเนา
- ถ้าต้องการเปลี่ยน Chip B โดยเฉพาะ: แตะช่อง Chip B ก่อน แล้วเลือกชิปจากกระเป๋า
- ไอเทม Crest Ring ต้อง Tamer Lv6; ของเริ่มต้นอื่นสวมได้ที่ Lv1
- ปุ่มหมุนใต้ตัวละครใช้ดูภาพ 4 ทิศเดิมของ Tamer
- ปิดด้วย X, Esc บนคอม หรือปุ่ม Back บน Android

## สเตตัสและเซฟ

กระเป๋าเริ่มต้นมี 18 ไอเทมและยังไม่สวมโดยอัตโนมัติ จึงเริ่มจากสเตตัสเดิมของ v14
HP/DS สูงสุดเพิ่มเมื่อใส่ของ แต่ HP/DS ปัจจุบันไม่เติมฟรี เมื่อถอดแล้วค่าปัจจุบันเกินเพดานจะถูก clamp
Defense ของเทมเมอร์ลดดาเมจจริง ขั้นต่ำ 1; เทมเมอร์ยังเป็นผู้สั่งการ คู่หูยังเป็นคนโจมตี
Digivice/Chip เพิ่ม ATK, HP หรือความเร็วคู่หู และคงอยู่ขณะเลเวลเพิ่ม/เปลี่ยนร่าง/ฟื้นจากไข่
HP0 ยังคงเป็น 0 เมื่อใส่ของ ต้อง Recover ตามระบบเดิม

ใส่/ถอดแล้วบันทึกทันทีลง party profile เดิมของเกม รวมทั้งจำนวนของใน bag และช่องที่สวมอยู่
ชื่อ application เดิมถูกคงไว้เพื่อให้อ่าน `user://` เดิมได้ เซฟ v14 ที่ไม่มี equipment จะได้รับ starter ในกระเป๋าเพียงครั้งแรกหลังอัปเกรด
ถ้าเซฟกระเป๋าว่างไว้ ระบบไม่แจก starter ซ้ำ

เกมต้นแบบยังเป็น local/offline: เปิดหน้าต่างนี้แล้ว pause โลกและคูลดาวน์ ขณะที่หน้าต่างยังรับ touch ได้
