# v14: แผนที่ผืนใหญ่ บรรยากาศ RO และแสงเงา

เวอร์ชันนี้แก้ฉากที่เดิมเป็นลาน 1280 × 720 ให้เป็นโลก 2D ต่อเนื่องขนาด **5120 × 3200** ใน File Island พื้นที่ประมาณ 17.8 หน้าจออ้างอิง 1280 × 720 มีหมู่บ้าน ถนนหลายเส้น ทางแยก ทุ่ง ป่า แม่น้ำ สะพานสองจุด พื้นที่บอส และประตูเนื้อเรื่องเดิม ผู้เล่นเดินข้ามพื้นที่เหล่านี้ได้โดยไม่โหลด Scene ระหว่างทาง

ตัวละครและระบบของ v13 ยังคงใช้ไฟล์เดิม: เดิน 4 ทิศ พร้อมเร่ง/หยุดอย่างสมูธ ท่าตีธรรมดา/ร่ายสกิลทุกระดับร่าง Projectile, AoE, EXP, ไข่คู่หู, Recover, Digivolve, คัตซีน, เควสต์, HUD เลือดและช่องแชต ไม่มีการใช้ภาพฉากใหม่แทนระบบเดินจริง

## เปิดเล่น

1. แตก ZIP เป็นโฟลเดอร์ใหม่ `mobile_openworld_v14` แล้ว Import `project.godot` ด้วย Godot **4.4.1** ขึ้นไป ใช้ Compatibility renderer ตามค่าในโปรเจกต์
2. รอ import ภาพและสคริปต์เสร็จ จากนั้นกด **F5** เข้าเกม ระบบยังใช้ชื่อแอปเดิมเพื่ออ่าน Save เดิม
3. ถ้า Save เดิมอยู่โซนหลัง ให้เปิด `scenes/world.tscn` แล้วกด **F6** เพื่อดู File Island ที่ขยายใหม่โดยตรง เควสต์และเลเวลเดิมไม่ได้ถูกรีเซ็ต
4. บนมือถือ ลาก Joystick เดิน แตะตัวมอนสเตอร์เลือกเป้า กด Attack/Skill ตามเดิม กดกรอบเควสต์เพื่อให้ Tamer นำทางและคู่หูเดินตาม
5. ปุ่ม **แสง: กลางวัน** ด้านบนกลางจอสลับเป็น **ช่วงเย็น** ได้ทันที เห็นแสงโคมชัดขึ้น
6. เปิด `tools/openworld_preview.tscn` แล้ว **F6** ดูทัวร์ 5 ช่วง: หมู่บ้าน → ทุ่ง → สะพาน → ป่า → หมู่บ้านยามเย็น พรีวิวใช้ Save แยกและตัดตำแหน่งเฉพาะระหว่างช่วง ไม่รีเซ็ต Save เกมหลัก

## โครงสร้างที่เพิ่ม

| ไฟล์ / Node | หน้าที่ |
|---|---|
| `data/openworld/file_island_layout.tres` | Resource ของขนาดโลก ผังถนน แม่น้ำ สะพาน และ seed การตกแต่ง |
| `scripts/open_world_layout.gd` | นิยามข้อมูลพิกัดโลกและฟังก์ชันเช็กถนน/น้ำ |
| `World/OpenWorldEnvironment` | สร้างพื้นเป็น material ซ้ำ พร็อพแยก เงาฉายบนพื้น collision และ bake NavigationPolygon ครั้งเดียว |
| `Actors/Tamer/Camera2D` | กล้องตามตำแหน่งจริง อยู่ในขอบโลก ไม่ใช้แผนที่ขนาดหน้าจออีกต่อไป |
| `scripts/world_prop.gd` | พร็อพมีรากที่เท้าเข้า Y Sort กับตัวละคร ยอดไม้จางเมื่อผู้เล่นอยู่ด้านหลัง |
| `scripts/world_lighting.gd` | CanvasModulate + DirectionalLight2D + โคม PointLight2D |
| `shaders/world_terrain.gdshader` | อ่าน texture atlas 4 ชนิดจากพิกัดโลก มีขอบถนนฟุ้งและน้ำเลื่อนเบา ๆ |
| `shaders/projected_shadow.gdshader` | เงาสีเย็นตาม alpha ของต้นไม้/บ้าน ฉายลงขวาล่างและมีความยาวจำกัด |
| `scripts/mobile_minimap.gd` | วาดผังถนน น้ำ สะพาน ผู้เล่น คู่หู ศัตรู และกรอบพื้นที่ที่กล้องกำลังเห็น |

พื้นไม่ได้ยืดจากภาพลานเดิม แต่ใช้ภาพ grass / dirt / stone / water เป็น material บน Polygon2D พร็อพใช้ Sprite2D แยกจึงเรียงหน้า/หลังกับตัวละครได้ ทิศแสงหลักมาจากซ้ายบน

## แสงและเงาทำงานอย่างไร

- `CanvasModulate` กำหนด ambient โลก ส่วน `DirectionalLight2D` เติมแดดอุ่น พื้นและสไปรต์รับแสงจริง
- เงาแดดเป็นการฉาย alpha ของภาพพร็อพลงบนพื้น เพื่อควบคุมความยาวและลดต้นทุน แสงแดดไม่ได้เปิด directional shadow แบบยาวไม่สิ้นสุด
- โคม 8 จุดใช้ `PointLight2D` กับ `GradientTexture2D` มี 2 ดวงแรกเปิด shadow แบบ PCF5 และมี `LightOccluder2D` จาก footprint พร็อพ โคมอื่นเติมแสงโดยไม่สร้าง shadow เพิ่ม
- ไฟโคมเปิดเฉพาะเมื่ออยู่ใกล้ผู้เล่น 850 พิกเซล ขณะกลางวันพลังงานต่ำ ช่วงเย็นเพิ่มแสงสีส้ม
- HUD อยู่ CanvasLayer แยก จึงอ่านเลือด แชต และปุ่มได้สว่างเหมือนเดิม

ปรับ `WorldLighting.apply_time_of_day()` เพื่อเปลี่ยน ambient/sun/energy และ `projected_shadow.gdshader` เพื่อปรับสีหรือ opacity ของเงา

## เส้นทางและการเกิดมอนสเตอร์

Navigation bake จาก footprint เดียวกับ collision ของบ้าน ลำต้น หิน และแม่น้ำ แล้วเพิ่มระยะ agent 20 พิกเซล ถนนหลักเว้นระยะต้นไม้สุ่มไว้ ศัตรู 13 จุดเกิดกระจายทั้งทุ่งและป่า ใช้การเช็กจุดเกิดก่อนสร้าง ไม่เกิดในหมู่บ้าน กลางน้ำ หรือลำต้น

แม่น้ำมีพื้นที่ชนจริง เว้นช่องผ่านเฉพาะสะพานสองแห่ง คู่หูและ Auto-Navigation ใช้ NavigationAgent2D เดิมเพื่ออ้อม ส่วนศัตรูในโลกใหม่นี้เพิ่ม NavigationAgent2D และเลือก Wander เป้าหมายที่เดินได้ ศัตรูใน Scene เดิมยังใช้พฤติกรรมเดิม

แก้ผังถนนและตำแหน่งสะพานใน `file_island_layout.tres` ก่อนแก้ตำแหน่ง NPC, ReachPoint, BossSpawner และ Portal ใน `world.tscn` ให้สอดคล้องกัน ตำแหน่งที่มีอยู่จัดไว้ให้เดินผ่านเส้นทางจริงแล้ว การเพิ่มขนาดโลกต้องจัดถนน/พร็อพ/จุดเกิดให้ครอบคลุมพื้นที่เพิ่มด้วย กล้องและมินิแมปอ่านขนาดจาก layout

## ภาพที่ใช้ในฉาก

ภาพใหม่สร้างด้วย **built-in imagegen** และเก็บต้นฉบับไว้ใน:

- `assets/openworld/terrain_v14.png` — atlas พื้น 4 ชนิด
- `assets/openworld/nature_v14.png` — ต้นไม้ พุ่ม หิน ดอกไม้
- `assets/openworld/village_v14.png` — บ้าน บ่อน้ำ ประตู โคม และสะพาน

ใช้ native AtlasTexture `.tres` เลือก region ของพร็อพ 12 ชิ้น ไม่แก้พิกเซลต้นฉบับ ข้อมูล region อยู่ `assets/openworld/ATLAS_REGIONS.json` และ **prompt ครบทุกภาพ** อยู่ `OPENWORLD_IMAGE_PROMPTS.json` สไปรต์ตัวละครและท่าต่อสู้เดิมไม่ได้สร้างซ้ำ

## การตรวจสอบ

ผลทดสอบจริงอยู่ `OPENWORLD_TEST_RESULTS.json` พร้อม engine version และจำนวน assertion แยกชุด ทดสอบระบบเดิมใน `tests/fixtures/arena_v13.tscn` เพื่อแยกข้อผิดพลาด combat/input ออกจากการเปลี่ยนภูมิประเทศ และทดสอบฉากโลกใหม่ใน `tests/openworld_test.tscn` ครอบคลุม:

- เป้าหมายเควสต์ไกลจากหมู่บ้านและคู่หูเดินตามจริง
- เดินชนริมแม่น้ำและเดินผ่านสะพานจริง
- path ข้ามแม่น้ำเลือกสะพาน
- จุดเกิดไม่ทับบ้าน/ต้นไม้/น้ำ/หมู่บ้าน
- กล้องตามและหยุดที่ขอบโลก
- แตะเลือกศัตรูหลังกล้องเลื่อน
- ร่าง/สกิลเดิม และ ambient / โคม / HUD แยก CanvasLayer

รันชุดโลกใหม่ด้วย:

```bash
godot --headless --audio-driver Dummy --fixed-fps 60 --path . res://tests/openworld_test.tscn
```

ตรวจภาพใน Godot Compatibility renderer จริงแล้ว ทั้งหมู่บ้านกลางวัน ทุ่ง สะพาน ป่า และไฟช่วงเย็น ภาพหน้าจออยู่ `docs/screenshots/` คลิปที่แนบเป็นการบันทึก viewport ของ Godot

## ขอบเขตเวอร์ชันนี้

ขยาย **File Island** เป็นแผนที่ต่อเนื่องผืนใหญ่ ส่วน Server Continent, Odaiba และ Spiral Mountain ยังเป็น Scene เดิมพร้อมระบบประตู/เควสต์เดิม เวอร์ชันนี้ยังเป็นต้นแบบเล่นในเครื่อง ไม่มี server MMO หรือการ stream โลกแบบไร้ขอบเขต ยังไม่ได้วัด FPS บนอุปกรณ์ Android จริง
