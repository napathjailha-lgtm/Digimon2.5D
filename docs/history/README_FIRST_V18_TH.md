# เริ่มใช้งาน v18 — Clean Mobile HUD

1. แตก Godot4_CleanHUD_v18.zip ลงโฟลเดอร์ใหม่ แล้ว Import ไฟล์ `mobile_clean_hud_v18/project.godot` ใน Godot 4.4.1 ขึ้นไป
2. รอ Import ภาพเสร็จแล้วกด F5 ใช้ Loading/Login/เลือก Tamer/เลือกคู่หูเดิม หรือเปิด `scenes/world.tscn` แล้ว F6 เพื่อทดสอบสนามโดยตรง
3. HUD เริ่มด้วยสถานะรวมซ้ายบน เมนู + ขวาบน แชตย่อ และมินิแมปซ่อน การตั้งค่าจากการเปิดครั้งก่อนจะถูกจำไว้
4. แตะเมนู + เพื่อเปิด กระเป๋า/สถานะ/เควสต์/ตั้งค่า/ดิจิไวซ์/แผนที่/แชต/ตัวละคร เมนูตัวละครกลับหน้าเลือกตัวละครเมื่อเข้าเกมผ่าน Login
5. ขวาล่าง: โจมตี/สกิล/พัฒนา/ชุดถัดไป/Auto โดย Recover จะแทนโจมตีเมื่อคู่หูสลบ
6. ชุดถัดไปเปลี่ยนเฉพาะหน้าสกิล ใช้สกิลร่างที่ปลดล็อกเควสต์แล้วโดยไม่ต้องเปลี่ยนตัวในสนาม ดาเมจใช้ ATK ของร่างสนามและ multiplier ของสกิล ค่า DS และคูลดาวน์ไม่ถูกล้าง
7. ตั้งค่า HUD เปลี่ยนขนาดปุ่ม 100%/115% ลดการเคลื่อนไหวเมนู แสดงมินิแมป ย่อแชต และสลับแสงกลางวัน/เย็นในแผนที่ Open World ได้
8. คู่มือพร้อมผัง Node และ GDScript ฉบับเต็มอยู่ใน `README_CLEAN_HUD_TH.md`; ภาพจากเกมจริงอยู่ใน `docs/previews/`

ไม่ต้องติดตั้ง Autoload ใหม่: GameManager, QuestManager, EquipmentManager, InventoryManager และ GameChat ตั้งค่าแล้ว ใช้ชื่อ application เดิมเพื่อคงตำแหน่งเซฟเดิม; ค่าความชอบ HUD อยู่ใน user://hud_preferences_v18.cfg แยกจากเซฟตัวละคร

โปรเจกต์เป็นเกมต้นแบบในเครื่อง ระบบ Login/Server/Chat ยังเป็นการจำลองตามเวอร์ชันก่อน ไม่มี backend MMORPG เพิ่มในงาน HUD นี้
