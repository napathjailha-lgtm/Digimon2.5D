# เริ่มใช้ v19 — Advanced Status & Survival

1. แตก Godot4_Survival_v19.zip ลงโฟลเดอร์ใหม่ และ Import `mobile_survival_v19/project.godot` ด้วย Godot 4.4.1 ขึ้นไป รอ Import ภาพเสร็จก่อนกด F5
2. ทดสอบเร็ว: เปิด `tools/survival_preview.tscn` แล้วกด F6 มีปุ่มหิวหมด / HP 19% / ฟื้นเต็ม และอาหารอยู่ในกระเป๋า ใช้ไฟล์เซฟสาธิตแยก
3. Tamer ใช้ HP / DS / ความอิ่ม / แรง คู่หูใช้ HP / MP สกิลหัก MP คู่หู เปลี่ยนร่างหัก DS Tamer
4. ความอิ่มลด 1 ทุก 5s ที่เล่น หิวหมดเสีย HP Tamer 5 ทุก 3s ต่อสู้ใช้แรง 1/s แรงหมดเสีย HP Tamer 5 ทุก 3s; สองเหตุพร้อมกันเสียรวม 10 ต่อรอบ
5. Tamer HP ต่ำกว่า 20%: หยุด Auto/Target/สกิล/ลูกไฟเก่า บังคับ Rookie และเดินกลับหา Tamer เปิดต่อสู้เมื่อ HP มากกว่า 20% (เท่ากับ 20% คงสถานะเดิม)
6. เมนู + → กระเป๋า → ผลไม้ดิจิตอล → กิน: อิ่ม +30 / HP Tamer +25 / แรง +10 น้ำ MP เติมคู่หู +30 และเนื้อเดิมเติม HP คู่หู +80
7. Safe Zone: พักฟื้น HP Tamer 10/3s, แรง 10/s, MP คู่หู 5/s; หยุดความหิว/ดาเมจ แต่ไม่เติมอาหารฟรี Recover ร่างไข่ด้วยระบบเดิม
8. Inventory/Status/Cutscene pause นาฬิกาหิวด้วย ไม่หักเวลาปิดเกมหรือแอปอยู่เบื้องหลัง เซฟเดิมเพิ่มฟิลด์ใหม่ให้ครบ เริ่มความอิ่ม/แรง/MP เต็มเมื่อโหลดเซฟ v18
9. DS ของร่างสูงยัง drain ตาม `MonsterData.ds_drain_per_second` จากระบบเดิม ตั้ง 0 ใน Resource ถ้าต้องการใช้ DS เฉพาะตอนกดเปลี่ยนร่าง
10. อ่านผัง Node, กติกาและโค้ดพร้อมคอมเมนต์ไทยใน `README_SURVIVAL_STATUS_TH.md` รูปจากเกมจริงอยู่ `docs/previews/Survival_v19_*.png`

ไม่ต้องตั้ง Autoload ใหม่ TamerSurvival เป็นลูกของ Tamer ชื่อ application เดิมคงไว้ให้เข้าถึงเซฟเดิม แนะนำใช้โฟลเดอร์ใหม่แทนลากไฟล์รวมกับ v18 เพื่อไม่สร้าง class_name หรือไฟล์สคริปต์ซ้ำ

ระบบเกม/Server/Login/Chat ยังใช้ต้นแบบเดิมในเครื่อง งานนี้ยังไม่ได้ build APK หรือทดสอบบนมือถือจริง
