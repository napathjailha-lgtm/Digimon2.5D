# Image-generation prompts — v24

Method: built-in image generation, one call per asset. Icons were generated with an opaque background and circularly cropped at runtime in Godot. VFX were generated with transparent_background=true; original alpha is preserved. Original generated PNG files are copied into this project. Godot imports them with a 256px size limit and mipmaps; originals remain untouched.
