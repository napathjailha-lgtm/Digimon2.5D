# v26 — Agumon & Gabumon Mega Evolution

เริ่มอ่านคู่มือรุ่นล่าสุดที่ **README_MEGA_V26_TH.md**
เพิ่ม Agumon → WarGreymon และ Gabumon → MetalGarurumon พร้อมภาพ สกิล และเซฟเดิม
Import `mobile_mega_lines_v26/project.godot` ด้วย Godot 4.4.1 แล้วกด F5

โปรเจกต์ Godot 4.4.1 / Compatibility / Mobile Landscape ต่อยอดจาก v25

1. แตก ZIP ลงโฟลเดอร์ใหม่ แล้ว Import `mobile_mega_lines_v26/project.godot`
2. รอ Godot import ภาพครั้งแรก จากนั้นกด F5 ผ่านหน้า Login/เลือกตัวละครเดิม
3. เปิดเมนูขวาบน → **ดิจิมอน** เพื่อดูหน้าสถานะใหม่
4. ต้องการดูแมพทันที: เปิด `scenes/world.tscn` แล้วกด F6

เวอร์ชันนี้มีแมพเดียว 10,240 × 6,400 พิกเซล ไม่มีวาร์ป มี 240 จุดเกิดมอนสเตอร์ปกติและบอสเนื้อเรื่องอีก 4 จุด
ใช้ **README_MEGA_V26_TH.md** สำหรับสายร่างใหม่ และ **README_SINGLE_WORLD_V25_TH.md** สำหรับผังโลก/เควสต์/หน้าสถานะ
คู่มือรุ่นก่อนหน้านั้นที่แนบไว้เป็นประวัติระบบเดิม

ไม่มี APK แนบในรอบนี้ สามารถ Export เองด้วย Android preset ที่มีอยู่ได้
