# คู่มือ v25 — เกาะเดียวขนาดใหญ่ และหน้าสถานะดิจิมอน

## เปิดโปรเจกต์

แตก ZIP เป็นโฟลเดอร์ใหม่ ไม่แตกทับโปรเจกต์ที่คุณแก้ไว้เอง เพื่อไม่ให้ไฟล์เก่าที่เลิกใช้ค้างปะปน
Import `mobile_single_world_v25/project.godot` ด้วย Godot 4.4.1 หรือรุ่น 4.x ที่เข้ากันได้ รอ import ภาพแล้วกด F5
F5 ใช้หน้าล็อกอิน/เลือกตัวละครเดิม ส่วน F6 บน `scenes/world.tscn` ใช้ทดลองฉากโดยตรง

## สิ่งที่เปลี่ยน

- ขยายโลกจาก 5,120 × 3,200 เป็น **10,240 × 6,400** พิกเซล: กว้าง/สูงอย่างละสองเท่า พื้นที่สี่เท่า
- ใช้ `world.tscn` เป็นฉากเกมเพลย์หลักฉากเดียว ถอดประตูวาร์ปทั้งหมดออกจากฉาก
- เพิ่มถนนเชื่อมทุ่ง ป่า แคมป์ และซากโบราณ สะพานข้ามแม่น้ำเพิ่มเป็น 4 จุด
- เพิ่มต้นไม้หลักประมาณ 520 ต้น พร้อมพร็อพย่อย แคมป์ 3 จุด และแสงโคมเพิ่มเติม
- เพิ่มเป็น **240 จุดเกิดปกติ + บอส 4 จุด** จากเดิม 12 จุดเกิดปกติ + บอส 1 จุด แต่ละจุดดูแลมอนสเตอร์หนึ่งตัว
- บอส Devimon, Etemon, Myotismon และ Piedmon รวมอยู่บนเกาะเดียว เป้าหมายเควสต์หลักทั้ง 8 หาได้ด้วย Quest Tracker
- ชื่อเมนูเดิม “สถานะ” เปลี่ยนเป็น **“ดิจิมอน”** เปิดหน้าพรีวิวตัวลงสนามและค่าพลังแบบใหม่
- คงชุดภาพตัวละคร สกิล ไอคอนและเอฟเฟกต์จาก v24 รวมถึงทีมคู่หู กระเป๋า อุปกรณ์ Survival และระบบ Recover

## จุดเกิดและประสิทธิภาพ

`scripts/world_population.gd` ใช้ seed คงที่จัดวางจุดเกิด หลีกเลี่ยงน้ำ อาคาร และหมู่บ้าน
ตั้ง `regular_population` ใน Node `WorldPopulation` เพื่อปรับจำนวนศัตรูปกติ บอสแยกอีก 4 ตัว

ระยะทำงานของ Spawner คือ 1,500 px รอบ Tamer เมื่อยังไม่เคยเข้าใกล้จะยังไม่สร้างมอนสเตอร์
ตัวที่สร้างแล้วและอยู่ไกลเกิน 1,800 px จะซ่อนและหยุด AI โดยเก็บ HP เดิมไว้ เมื่อกลับมาใกล้จะใช้ตัวเดิม
การเดินถอยออกแล้วกลับมาจึงไม่ฟื้น HP ศัตรูให้เต็ม ส่วนศัตรูที่ตายแล้วนับ Respawn ตามปกติและรอสร้างใหม่เมื่อผู้เล่นกลับมาใกล้
มอนสเตอร์ที่เคยพบจะยังมี Node ในหน่วยความจำจนตายหรือออกจากฉาก: ระบบนี้ลดภาระ AI ไม่ใช่ระบบ streaming ทรัพยากรทั้งโลก

ตัวปกติที่เพิ่มใหม่ Respawn 10 วินาที บอสใหม่ 25 วินาที จุดเกิดเดิมคงค่าเดิมเพื่อรักษาพฤติกรรมการเล่น
AI หยุดนอกระยะและไฟที่ทอดเงายังคงจำกัด 2 ดวงใกล้ผู้เล่น ยังควรลองปรับจำนวนมอนสเตอร์บนมือถือเป้าหมายจริง

## หน้าดิจิมอน

เปิดเมนูขวาบน → ดิจิมอน
แสดง Level, EXP, รูปเคลื่อนไหวของร่างปัจจุบัน, ประเภท/ธาตุ และค่าจริงของตัวลงสนาม
ถ้าคู่หูสลบจะพรีวิวไข่และ HP 0 ไม่แสดงว่าต่อสู้ได้

| ช่อง | ความหมาย |
| --- | --- |
| HP | เลือดปัจจุบัน / สูงสุดของคู่หู |
| MP | พลังสกิลของคู่หู ส่วน DS ยังคงเป็นของ Tamer บน HUD |
| AT | พลังโจมตีจริงหลังโบนัสของระบบเดิม |
| AS | ช่วงเวลาขั้นต่ำระหว่างการโจมตีธรรมดา หน่วยวินาที |
| CT / HT | โอกาสคริติคอล / ความแม่นยำ |
| DE / BL / EV | เกราะ / โอกาสบล็อก / โอกาสหลบ |
| MS | ความเร็วเคลื่อนที่ |

แตะรูปสกิลเพื่อดูชื่อ ความแรง ค่า MP คูลดาวน์ ระยะ และรัศมี
ช่องว่างเป็นช่องที่ร่างนั้นไม่มีสกิล ช่อง **Memory Skill** เป็นช่องเตรียมไว้และปิดการใช้งาน เนื่องจากโปรเจกต์ยังไม่มีระบบเรียน Memory Skill

CT, HT, DE, BL, EV มีข้อมูลใน `MonsterData` และเชื่อมกับดาเมจจริง ไม่ใช่ตัวเลขตกแต่ง
ค่าเริ่มต้น CT/DE/BL/EV = 0, HT = 100% เพื่อรักษาสมดุลเดิม ทุกครั้งที่เปลี่ยนร่าง UI จะอ่าน Resource ของร่างใหม่
คริติคอลเริ่มที่ 1.5 เท่า; การป้องกันคิดหลบ → หักเกราะ → บล็อกลดครึ่งหนึ่ง ไม่มีดาเมจติดลบ
ยังไม่มีปุ่มจัดสรรแต้มสเตตัส: ปรับข้อมูลแต่ละร่างผ่าน Inspector ของ Resource

หน้าต่างใช้ Container และ ScrollContainer เว้น Safe Area รอยบาก เมื่อเปิดจะพักเกมและปิดแล้วคืนเวลา
ปุ่มรับ InputEventScreenTouch จริง จึงทำงานกับการตั้งค่า `emulate_mouse_from_touch=false` ของโปรเจกต์นี้

## ไฟล์หลักที่ปรับ

- `scripts/world_population.gd`: จุดเกิดและเป้าหมายเควสต์บนเกาะเดียว
- `scripts/monster_spawner.gd`: ระยะทำงานและพัก AI โดยไม่รีเซ็ต HP
- `scripts/open_world_layout.gd`, `data/openworld/file_island_layout.tres`: ขนาดแมพ ถนน สะพาน
- `scripts/open_world_environment.gd`: ภูมิประเทศ พร็อพ แคมป์ collision และ nav
- `scripts/status/`: หน้าดิจิมอน พรีวิว และปุ่ม Touch
- `scripts/mobile_hud.gd`, `scripts/collapsible_hud_menu.gd`: เชื่อมเมนูใหม่และกันคำสั่งสนามระหว่างเปิดหน้าต่าง
- `scripts/monster_data.gd`, `scripts/partner_monster.gd`: สเตตัสต่อสู้ที่หน้าสถานะอ่าน
- `scripts/quest_manager.gd`, `scripts/GameManager.gd`, `data/quests/`: เควสต์และการอ่านเซฟโซนเก่า

ไฟล์ scene ชื่อโซนเก่ายังคงอยู่เป็น alias เข้าสู่ world.tscn เพื่อรองรับโค้ดที่อ้างพาธเดิม ไม่มีแมพอีกชุดอยู่ข้างใน
โหลดเซฟโซนเก่าแล้วกลับ File Island โดยเก็บเควสต์ที่ผ่าน เลเวล HP และข้อมูลปาร์ตี้ไว้
ไม่มีการล้างเซฟอัตโนมัติ
